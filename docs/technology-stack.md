# StudyMatch Technology Stack

## Frontend

StudyMatch will use React with Vite for the frontend application.

React provised a component-based approach that supports modularity, maintainability anbd reuse of user-interface components. Vite provides a good development enviroment with fast development and build tooling

## Backend

The backend will be implemented using Java and Spring Boot

Spring Boot provides a structured environment for devolping REST APIs and integrates well withg persistence, validation and testing tools.


## API

Communication between the frontend and backend will use a REST API, with JSON as the primary data exchange format. 


## Persistence

MySQL will be used as the relational database management system

Spring Data JPA with Hibnernate will be used for persistence in the backend. Integrates naturally with Spring Boot which makes development more intuitive and lightweight

## Build and Dependency Management

Maven will be used for backen build and dependency management

Honestly it is just what we re used to. 

## Version Control and Project Management

Git will be used for version control and GitHub will be used for
repository hosting and project management.

Development work will follow the agreed workflow:

Issue → Branch → Implementation → Pull Request → Review → Merge
